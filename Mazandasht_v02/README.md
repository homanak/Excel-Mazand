# مازندشت — سری جدید (v02)

پوشه‌ی `Mazandasht_v02` نسخه‌ی بازطراحی‌شده و کوتاه‌نام‌شده‌ی سامانه است. فایل‌های v01 دست‌نخورده در پوشه‌ی
`Mazandasht_System_v01` می‌مانند تا مقایسه و بازگشت آسان باشد.

---

## ۱) فایل‌ها

| فایل | نقش | از فایل قبلی |
|---|---|---|
| `00_Master.xlsx` | فایل مادر: حساب‌ها، گروه‌ها، عملیات، سبد، محصول، بانک، پارامترها | INFO.xlsx |
| `01_Entry.xlsx` | **تنها فایل ورود داده**: باسکول، سبد، پرداخت، دفتر، خلاصه، کنترل پز | 01_Register.xlsx |
| `02_Bank.xlsx` | تراکنش بانکی، چک، مغایرت‌گیری | 02_Bank.xlsx |
| `03_Report.xlsx` | صورت‌حساب باغدار / بارفروش / فروشنده سبد | 03_Report.xlsx |
| `04_Inv.xlsx` | فاکتور با تیک انتخاب سطرها | 04_Invoice.xlsx |
| `05_Bal.xlsx` | تراز ۴ و ۶ ستونی، انبار، کنترل، بین‌بانکی | 05_Balance.xlsx |
| `06_Buyers.xlsx` | ریز بار بارفروشان، ماهانه، مانده | 06_LoadBuyers.xlsx |
| `07_Demo.xlsx` | نمونه ساده برای آموزش | 07_Sample.xlsx |

هر هشت فایل در یک پوشه بمانند؛ همه‌ی ارتباط‌ها نسبی و به `01_Entry.xlsx` است.

## ۲) نام شیت‌ها (کوتاه و انگلیسی)

| فایل | شیت‌ها |
|---|---|
| 00_Master | Home · Co · Par · Grp · Acc · Op · Bsk · Prd · Bnk · List · Sync · Help |
| 01_Entry | Home · **Scale** · **Crate** · **Pay** · **Book** · **Sum** · **POS** · Sync · Help |
| 02_Bank | Ov · Txn · Chq · Rec · Sum · Sync · Help |
| 03_Report | Ov · Grw · LBuy · BSel · Grp · Sync · Help (به‌همراه Data پنهان) |
| 04_Inv | Inv · Sync · Help (به‌همراه Data پنهان) |
| 05_Bal | Ov · B4 · B6 · Grw · LBuy · BSel · Stock · Audit · IBank · Sync · Help |
| 06_Buyers | Ov · Det · Mon · Buyers · Sync · Help |

معنی: Scale = باسکول، Crate = سبد، Pay = پرداخت، Book = دفتر معین، Sum = خلاصه،
Grw = باغداران، LBuy = بارفروشان، BSel = فروشندگان سبد، Stock = موجودی، IBank = بین‌بانکی.

## ۳) چیدمان و چاپ

- **همه‌ی شیت‌ها راست‌به‌چپ** هستند (حتی شیت‌های پنهان).
- **همه‌ی شیت‌ها A4** با سربرگ (نام شرکت + عنوان فایل + نام شیت) و فوتر (نام فایل + «صفحه X از Y»).
- محدوده چاپ، تکرار سطر سرستون و «جا شدن در عرض یک صفحه» برای همه شیت‌ها تنظیم شده است.

## ۴) قواعد حسابداری این نسخه

همه‌ی این قواعد از «جدول عملیات» شیت `Sync` می‌آیند؛ پس با همان ساختار قبلی سازگارند.

1. **انعام مصطفی حساب مستقل دارد** (`X001`). با انتخاب این نوع عملیات در باسکول:
   حساب صادرات ۲۰۰۶ (`BANK02`) **بدهکار** و انعام مصطفی **بستانکار** می‌شود.
   هر پرداخت/انتقال بانکی به مصطفی هم در شیت `Pay` ثبت می‌شود و کنترل آن در شیت `POS` صفر می‌ماند.
2. **مبلغ خروجی بار = درآمد باسکول.** هر مبلغی که برای خروج بار ثبت شود به حساب ۲۰۰۶ می‌رود و
   **به حساب صاحب بار ربطی ندارد**. برای همین در عملیات «سایر خروج»، حساب پیش‌فرض `BANK02` و
   طرف مقابل `X002` (درآمد باسکول) شده است.
3. **فروش متفرقه** (و صادراتی): ستون «کد حساب / مقصد وجه» = حسابی که پول **به آن واریز شده**
   (هر بانک یا صندوق، مثلاً کارت‌به‌کارت به بانک دیگر). طرف مقابل، `X006` فروش مرکبات است.
4. **فروش به بارفروش** مثل قبل فاکتور واقعی می‌خورد (وزن × فی روی حساب بارفروش) و مبلغ باسکول
   جداگانه از ستون «مبلغ پوز/باسکول» به ۲۰۰۶ می‌رود.

## ۵) شیت POS — کنترل پز و واریزی روز بعد

در `01_Entry` شیت تازه‌ای به نام `POS` اضافه شده است:

- ستون «پز باسکول» خودکار است: هر خط دفتر (`Book`) که از باسکول به `BANK02` بدهکار شده باشد.
- واریزی روز بعد را در شیت `Pay` ثبت کنید: نوع **دریافت**، روش **کارت/پوز**، بانک مقصد **BANK02**.
  اگر پول به بانک دیگری کارت‌به‌کارت شده، همان بانک را انتخاب کنید؛ در ستون «کارت‌به‌کارت» می‌آید.
- اگر روز واریز با روز پز یکی نیست، تاریخ واریز را در ستون B بنویسید.
- اختلاف بیش از ۱٬۰۰۰ ریال با **⚠** و تراز با **✓** نشان داده می‌شود.
- بلوک دوم همان شیت، کنترل «۲۰۰۶ ↔ انعام مصطفی» است و باید همیشه صفر بماند.

> در فایل تحویلی چند ردیف نمونه وجود دارد؛ بعد از پاک کردن آن‌ها و ثبت داده‌ی واقعی، وضعیت‌ها ✓ می‌شوند.

## ۶) اولین بار که فایل را باز می‌کنید

1. `00_Master.xlsx` را باز کنید؛ اگر حساب یا نوع عملیات جدیدی اضافه کردید، ذخیره کنید.
2. `01_Entry.xlsx` را باز کنید و پیام به‌روزرسانی لینک را تأیید کنید:
   **Data ← Edit Links ← Update Values**.
3. بقیه فایل‌ها (02 تا 07) را باز کنید؛ همین کار را یک بار انجام دهید.
4. اگر فایلی را جابه‌جا کردید، همه‌ی فایل‌ها را با هم جابه‌جا کنید (لینک‌ها نسبی‌اند).

## ۷) بازسازی نسخه

اسکریپت‌های ساخت این نسخه در پوشه‌ی `build2/` هستند:

```bash
python build2/make.py
```

- `xf.py`: تغییر نام شیت‌ها و فایل‌ها، راست‌به‌چپ کردن، A4 و سربرگ/فوتر، و **تعمیر ۷٬۱۹۶ فرمول معیوب** نسخه قبلی.
- `entry.py`: قواعد جدید عملیات، شیت POS، متن راهنما و کارت‌های Home.
- `make.py`: ساخت کل مجموعه در `Mazandasht_v02/`.

## ۸) گام‌های بعدی (به‌ترتیب پیشنهادی)

- اتصال خودکار «واریز ۲۰۰۶» از فایل `02_Bank` به شیت POS (الان در `Pay` ثبت می‌شود).
- افزودن شیت کنترل کارت‌به‌کارت به تفکیک بانک در `02_Bank`.
- بازطراحی صفحات گزارش با استاندارد چاپی جدید و افزودن فیلتر تاریخ.
