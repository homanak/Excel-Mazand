# مجموعه مازندشت — نسخه ۰۱ (Excel 2013، بدون ماکرو)

این پوشه یک سیستم کامل حسابداری باسکول و سورتینگ مرکبات است. همه فایل‌ها باید **در همین پوشه** بمانند؛
چون فایل‌های گزارشی به `01_Register.xlsx` لینک هستند و مسیر نسبی دارند.

## قواعد ثابت سیستم

- **کدها هیچ‌وقت عوض نمی‌شوند؛ فقط عنوان‌ها قابل ویرایش‌اند.**
- تاریخ‌ها شمسی و به شکل `1405/07/10`؛ ساعت‌ها `09:30`؛ اعداد با ارقام لاتین.
- **وزن خالص** = وزن باسکول − (تعداد سبد × وزن تار سبد P01)، و برای خرید ۱٪ افت (P02) کم می‌شود.
- **مبلغ** = وزن خالص × فی، گردشده به هزار ریال. اگر «مبلغ دستی» پر شود، همان ملاک است.
- **خرید از باغدار**: باغدار بستانکار، موجودی مرکبات بدهکار.
- **فروش بار به بارفروش**: بارفروش بدهکار، فروش بستانکار؛ مبلغی که پوز باسکول می‌گیرد
  به حساب **صادرات ۲۰۰۶ (BANK02 / BN02)** می‌رود و روی حساب بارفروش اثر ندارد.
- **باسکول دیگران**: وزن مهم نیست؛ فقط مبلغ باسکول — طرف حساب بدهکار، درآمد باسکول بستانکار.
- **انعام مصطفی**: مصطفی بستانکار، پوز ۲۰۰۶ بدهکار.
- **آبگیری**: وزن و طرف حساب، مبلغ درآمد آبگیری.
- هر فایل یک شیت **Sync** دارد (داده ثابت، قفل) و یک شیت **Help** (راهنمای فارسی).

## اگر اعداد صفر باز شد

فایل‌های ۰۲ تا ۰۶ به فایل ثبت لینک هستند. وقتی فایل را باز می‌کنید Excel می‌پرسد
«به‌روزرسانی پیوندها؟» → **Update** را بزنید. اگر نپرسید:

> **Data ← Edit Links ← Update Values**

همه فایل‌ها باید در یک پوشه باشند و نام `01_Register.xlsx` تغییر نکند.
